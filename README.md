# 分紙生成工具

給 ICT、電腦、DT 科老師用的分紙工具：匯入各班學生，設定這學期的評核項目、滿分和計分公式，輸入分數後即時計出學期總分，再匯出成可直接列印簽分的 Excel 分紙。

整個工具只有一個檔案 `index.html`，不用安裝，用瀏覽器打開即可。

## 功能

1. **學生名單**：可直接匯入舊分紙 Excel（每個工作表當一班，自動找出班號、中英文姓名、性別），或從 Excel 貼上，或從另一份分紙複製。
   - **ICT 選修**：學生來自不同班別，不按班別分開，整組放在一起；名單列出班別、學號、姓名（匯入時讀「班別」「學號」「姓名」欄）。
2. **評核項目**：按類別（堂課、功課、測驗、默書、課堂表現……）加入項目，每項有內容、日期、滿分、折算分，可設為加分項。
   - **DT 上下半班**：每位學生標明上半班或下半班（可按班號一鍵平分）；項目可設為全班、上半班或下半班適用，例如兩組不同的設計習作及製作習作。每位學生只計自己組別的項目，Excel 分紙按組別欄用公式計分，不適用的格以灰色顯示。
3. **計分方式**
   - 按項目折算：每項折算成指定分數，加起來再按比例變成學期總分（例：默書 × 4.4，÷ 219 × 50）。
   - 按類別比重：例如功課 30%、測驗 50%、課堂表現 20%。
   - 可設總分上限、小數位、空白當 0 分或不計入。
4. **輸入分數**：像試算表一樣輸入，Enter 移到下一位學生，可從 Excel 貼上整欄分數。
   - `缺`＝缺交，當 0 分
   - `免`＝豁免，該項不計入，其餘項目按比例補足
5. **總覽及匯出**
   - 匯出 Excel：每班一頁，剛好印一張 A4（連學生簽署欄），總分欄是 Excel 公式。
   - 固定格式：每班一律 35 行（可改），人數較少的班留空行，所有班別欄位、行高、縮放相同。
   - 每班分成「原得分」（填寫真實分數）及「折算後分數」（全部公式，從原得分計算）。打字只需填分數、WPM（及準確度），換算得分由公式按已定分界計出。
   - 空白分紙：只有名單和公式，給同事填寫，填好即可影印簽分；可保護公式、限制只可輸入 0 至滿分或「缺」「免」。
   - 附「總分表」及「評核項目」工作表。
6. **打字換算**（電腦 / ICT）：英文打字、中文打字分開處理，貼上全級成績後同時計出三個方案，比較後填入分紙。
   - 方案一：全級排名分級（每 20% 一級，同分取較高一級）
   - 方案二：預先定好速度標準（可設準確度門檻，可按全級成績自動定分界）
   - 方案三：按比例計分（完成者最低 10 分，全級最高 10% 滿分）
   - 分紙及匯出的 Excel 會列出每位學生的原始分數及 WPM，旁邊是換算得分。
   - 鎖定計算方法：先用已考學生定出分界並鎖定，之後補考學生的成績（可在結果表直接輸入）按同一分界計分，不影響其他人。

## 資料儲存

- 在 claude.ai 的版本：資料自動儲存到自己的帳戶，只有自己看得到。
- 直接打開 `index.html`（或用 GitHub Pages）：資料儲存在該電腦的瀏覽器。請定期在「總覽及匯出 → 下載備份」保存備份，換電腦時用「還原備份」。

學生資料不會上載到這個 repo。
